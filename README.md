# Austin Aux — Free Audio Plugins

Official native installers, documentation, and releases for free audio plugins by [Austin Aux](https://austinaux.com).

## 🚀 Available Plugins

### 1. AuxClip Pro
* **Description:** Mastering Clipper & True-Peak Maximizer with visual ceiling and drive control.
* **Formats:** VST3, Audio Units (AU), Standalone Application.
* **Platforms:** macOS (Apple Silicon & Intel) and Windows (64-bit).
* **Learn More:** [austinaux.com/tools/aux-clip-pro](https://austinaux.com/tools/aux-clip-pro)

### 2. AuxFormant

* **Platforms:** macOS (Apple Silicon & Intel) and Windows (64-bit).
* **Learn More:** [austinaux.com/tools/aux-formant](https://austinaux.com/tools/aux-formant)

### 3. AuxHarmonizer
